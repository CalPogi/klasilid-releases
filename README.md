# Klasilid downloads

Klasilid takes class attendance when students tap their card at the classroom door, and keeps working without internet.

Get the apps from the **[latest release](https://github.com/CalPogi/klasilid-releases/releases/latest)**:

- **Android** (7 or newer): `Klasilid.apk`
- **Windows** (10 or 11, 64-bit): `Klasilid-Setup.exe`

Or open Klasilid in a browser from the Klasilid website.

This repository holds only the release files. The source code is private.
